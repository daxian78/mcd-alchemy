## 正文框架（约 3000 字，图为主）

### 开头（100 字）
WorkBuddy 是我日常的 AI 工作台。这次尝试用它完成一个完整的参赛作品：
从设计 Skill、实测官方 MCP、生成演示页，到自动化部署——全程在 WorkBuddy 内完成，零代码环境切换。

### 第一部分：为什么选麦当劳 MCP（项目背景）
- 30+ 工具的真实业务全链路（点餐/支付/会员/营销）
- 国内少见的高质量 MCP 样板，适合做落地参考

### 第二部分：WorkBuddy 全流程实录（核心章节，每步配图）
1. **连接器配置**：mcd-order 接入（截图：配置 JSON + 工具列表）
2. **Skill 设计**：三大模式的 SKILL.md 结构（贴结构图）
   - 点餐代理：七步流程图（时段→门店→预算→组合→券检查→方案→建单）
   - 安全护栏设计：消耗型操作三重确认、券的四道适用性检查
3. **实战对话实录**（截图拼图）：
   - 深夜点餐：预算 → 带图方案 → 换配 → 建单
   - 踩坑与修复：AI 把早餐券推给晚餐场景 → "四道检查"护栏的设计过程
4. **自动化**：每日情报简报（weather + 活动 + 积分 + 保底速算），WorkBuddy automation 每天 08:00 自动推送
5. **演示页与部署**：demo 页开发 + GitHub Actions 双通道部署

### 第三部分：WorkBuddy 生态的加成（专项奖励落点）
- WorkBuddy 路径 vs GitHub Actions 路径对比表（零代码 vs 配置化）
- `workbuddy-setup.md`：其他 WorkBuddy 用户零代码复刻本项目的完整指南
- 图片素材生成（banner）、演示页发布、automation——**全在一个工作台内闭环**

### 第四部分：模式可迁移（升华）
- "消费决策副驾驶"是通用模式：换成咖啡/奶茶/加油/话费，任何品牌 MCP 都能套
- 附迁移检查清单（连接器接入 → Skill 三模式设计 → 演示页 → 自动化 → 内容分发）
